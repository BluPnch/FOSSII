# Лабораторные работы по "фундаментальным основам систем искусственного интеллекта"

## Лабораторная 1: MLP для распознавания грибов

Реализация MLP с двумя скрытыми слоями и сигмоидой для классификации грибов на съедобные и ядовитые. Обучение - Backpropagation и градиентный спуск без оптимизаторов. Проведена оценка модели и построены ROC-кривая и график потерь.
