# Фундаментальные основы систем искусственного интеллекта

Лабораторные работы по классификации табличных данных, распознаванию и восстановлению изображений и прогнозированию временных рядов.

| Лабораторная работа | Что сделано |
| --- | --- |
| [№ 1. Классификация грибов](lab1/README.md) | Однослойный и многослойный перцептроны на NumPy определяют съедобность грибов по признакам из набора UCI Mushroom. |
| [№ 2. Распознавание цифр MNIST](lab2/README.md) | Свёрточная сеть на NumPy классифицирует рукописные цифры. Исследованы число слоёв и фильтров, размер ядра и пулинг. Две архитектуры обучены по 60 эпох для сравнения. [Результаты сравнения](lab2/results/investigations/compare_60_epochs/REPORT.md) |
| [№ 3. Прогнозирование энергопотребления](lab3/README.md) | RNN, GRU и LSTM прогнозируют потребление сталелитейного предприятия на 15 минут вперёд. Проверены сочетания гиперпараметров, правила ранней остановки и дополнительные входные признаки. [Гиперпараметры](lab3/results/ideal/REPORT.md) · [Признаки](lab3/results/features/REPORT.md) |
| [№ 4. Восстановление изображений MNIST](lab4/README.md) | Трёхкомпонентная VAE-GAN восстанавливает цифры после добавления гауссовского шума. На одних и тех же 10 000 зашумлённых изображениях MSE сохранённой модели NumPy оказалась на 7,7% ниже, чем у модели PyTorch. [Метрики и примеры восстановления](lab4/README.md#сравнение-на-одинаковых-тестовых-входах) |

В README каждой работы описаны модели и результаты. Команды установки и запуска приведены в её `RUNNING.md`.
