# Фундаментальные основы систем искусственного интеллекта

Лабораторные работы по классификации табличных данных, распознаванию изображений и прогнозированию временных рядов.

| Лабораторная работа | Что сделано |
| --- | --- |
| [№ 1. Классификация грибов](lab1/README.md) | Однослойный и многослойный перцептроны на NumPy определяют съедобность грибов по признакам из набора UCI Mushroom. |
| [№ 2. Распознавание цифр MNIST](lab2/README.md) | Свёрточная сеть на NumPy классифицирует рукописные цифры. Исследуется влияние архитектуры на ошибку и время обучения. |
| [№ 3. Прогнозирование энергопотребления](lab3/README.md) | RNN, GRU и LSTM прогнозируют потребление на 15 минут вперёд по данным сталелитейного предприятия. Сравниваются гиперпараметры и входные признаки. |

В README каждой работы описаны модели и результаты. Команды установки и запуска приведены в её `RUNNING.md`.
