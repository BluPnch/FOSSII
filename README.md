# Лабораторные работы по "фундаментальным основам систем искусственного интеллекта"

## Лабораторная 1: MLP для распознавания грибов

Реализация MLP с двумя скрытыми слоями и сигмоидой для классификации грибов на съедобные и ядовитые. Обучение - Backpropagation и градиентный спуск без оптимизаторов. Проведена оценка модели и построены ROC-кривая и график потерь.

## Лабораторная 2: CNN для распознавания цифр MNIST

Свёрточная нейронная сеть, написанная с нуля на NumPy: два свёрточных слоя, average-пулинг, два полносвязных слоя, обучение обратным распространением ошибки до средней ошибки 0.0001. Посчитаны матрица неточностей, accuracy, precision, recall, F-мера, ROC-кривые и AUC, построен t-SNE и разобраны причины ошибок. Архитектура выбрана по итогам пяти исследований (число слоёв, фильтров, размер ядра, окно и тип пулинга). Отчёт — в [lab2/README.md](lab2/README.md).
