# Лабораторная работа №1: MLP для распознавания грибов

Реализация многослойного перцептрона (MLP) для классификации грибов по признакам.

**Задача:** определить, является гриб съедобным или ядовитым.

## Модель

- 2 скрытых слоя: 32 и 16 нейронов
- функция активации сигмоида
- 2 выходных нейрона
- обучение - Backpropagation + градиентный спуск
- оптимизаторы не используются
- MLP реализован с нуля на NumPy

## Оценка

Рассчитаны метрики:

- Accuracy
- Precision
- Recall
- F1-score

Построены:

- график зависимости функции потерь от количества итераций;
- ROC-кривая.

## Технологии

Python, NumPy, Pandas, Matplotlib, Jupyter Notebook
