# Лабораторная работа № 1. Классификация грибов

Однослойный и многослойный перцептроны определяют, съедобен гриб или ядовит, по категориальным признакам из [UCI Mushroom](https://archive.ics.uci.edu/dataset/73/mushroom).

[Установка зависимостей и запуск](RUNNING.md)

## Модели

- Однослойный перцептрон использует пороговую активацию и корректирует веса при ошибке классификации. [Скрипт](lab1_olp.py) · [ноутбук](lab1_olp.ipynb)
- Многослойный перцептрон на NumPy использует два скрытых слоя на 32 и 16 нейронов, сигмоиду и два выхода. Веса обучаются обратным распространением ошибки и градиентным спуском. [Скрипт](lab1_mlp.py) · [ноутбук](lab1_mlp.ipynb)

## Оценка

Для обеих моделей рассчитываются accuracy, precision, recall и F1. Для однослойного перцептрона строятся график ошибок по итерациям и матрица ошибок. Для многослойного — график функции потерь и ROC-кривая.
