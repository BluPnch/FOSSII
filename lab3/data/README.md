# Steel Industry Energy Consumption

Локальная исходная копия: `Steel_industry_data.csv`. Оригинальный архив сохранён рядом:
`steel_industry_energy_consumption.zip`. Обучение не использует интернет.

- Источник: https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption
- Архив: https://archive.ics.uci.edu/static/public/851/steel+industry+energy+consumption.zip
- Авторы: Sathishkumar V E, Changsun Shin, Yongyun Cho (2021).
- DOI: https://doi.org/10.24432/C52G8C
- Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Дата скачивания: 3 ноября 2026 года.

Исходный CSV не изменяется. Даты разбираются как `день/месяц/год часы:минуты`.
