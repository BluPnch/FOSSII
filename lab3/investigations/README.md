# Исследования гиперпараметров

## Совместная настройка и итоговая модель

После однофакторного исследования выполните из каталога `lab3`:

```powershell
python investigations/ideal.py --workers 3
```

Скрипт проверяет сочетания лучших значений на трёх seed для каждой архитектуры,
сравнивает их с базовыми конфигурациями по среднему validation MSE и сохраняет
обученную итоговую модель с заранее фиксированным seed 42. Дополнительно сравнивает
бюджеты эпох, patience и min_epochs по записанным траекториям. Тестовые метрики
вычисляются после выбора; исходные результаты `baseline_30` сохраняются.

[Итоговый отчёт и сравнение с исходной моделью](../results/ideal/README.md).
Веса: `results/ideal/ideal_model.pt`, настройки: `results/ideal/ideal_config.json`.

Запуск из корня проекта:

```powershell
python lab3/investigations/run.py --workers 3
```

Все 33 обучения выполняются локально на CPU, исходный датасет не сокращается.
Число одновременно работающих процессов задаёт `--workers`, каждый использует
один поток PyTorch. Завершённые запуски переиспользуются при совпадении настроек,
хеша датасета и хешей исходного кода. Для полного повторения есть `--force`.
После прерывания достаточно повторить ту же команду: незавершённые модели обучатся заново.

## План

| Исследование | Значения | Архитектуры |
| --- | --- | --- |
| Число эпох | лучшие веса до 30, 60, 100 эпох одной траектории | RNN, GRU, LSTM |
| Длина окна | 8, 24, 48 отсчётов (2, 6, 12 часов) | RNN, GRU, LSTM |
| Размер скрытого состояния | 16, 32, 64 | RNN, GRU, LSTM |
| Learning rate | 0.0003, 0.001, 0.003 | RNN, GRU, LSTM |
| Batch size | 128, 256, 512 | RNN, GRU, LSTM |
| Seed | 7, 42, 123 | RNN, GRU, LSTM |

Варьируется один параметр относительно базы: окно 24, hidden size 32,
learning rate 0.001, batch size 256, seed 42. Базовые обучения общие для исследований,
поэтому требуется 11 уникальных конфигураций на каждую архитектуру.
Лимит — 100 эпох, минимум — 60, early stopping — 25 эпох без улучшения валидации.

Во всех экспериментах одинаковые целевые даты: первые 48 строк используются только
как контекст, затем 24 480 обучающих целей, 5 256 валидационных и 5 256 тестовых.
Выбор весов и конфигураций делается по validation MSE. Тест вычисляется только для
трёх выбранных моделей после завершения исследований.

## Результаты

Подробный отчёт автоматически создаётся в
[results/investigations/README.md](../results/investigations/README.md).
Там же сохраняются таблицы метрик и графики, в том числе кривые обучения
и валидации для всех вариантов каждого исследования. В `runs/` находятся
веса, логи, CSV истории каждой эпохи и валидационные прогнозы всех 33 запусков.

Итоговые выбранные модели, их истории, тестовые метрики и графики сохраняются
в `lab3/results`. Первоначальное сравнение за 30 эпох сохранено отдельно
в `lab3/results/baseline_30`.
